
# ❤️ Eksplorasi Data Penyakit Jantung (EDA)

Repositori ini berisi proyek *Exploratory Data Analysis (EDA)* terhadap dataset penyakit jantung dari UCI yang tersedia di Kaggle.

## 📌 Deskripsi Dataset
- Sumber: [Kaggle - Heart Disease UCI](https://www.kaggle.com/datasets/ronitf/heart-disease-uci)
- Target: Diagnosis penyakit jantung (`num`) → 0 = Tidak, 1 = Ya
- Jumlah Fitur: 14 atribut seperti usia, jenis kelamin, tekanan darah, kolesterol, tipe nyeri dada, dll.

## 🔍 Langkah EDA
- Membersihkan data dan menangani nilai yang hilang (*missing values*)
- Mengubah label target menjadi format biner
- Visualisasi data numerik dan kategorikal
- Analisis korelasi antar fitur dan insight dari data

## 📁 Isi File
- `EDA_Heart_Disease.py`: Script Python untuk proses EDA
- `heart_disease_uci.csv`: Dataset yang digunakan
- (Opsional) `Figure_x.png`: Visualisasi yang dihasilkan
- (Opsional) `Laporan_EDA.pdf`: Laporan akhir tugas

## 🎯 Tujuan
Mengevaluasi pola dan fitur penting yang berpengaruh terhadap risiko penyakit jantung sebagai dasar untuk pengembangan model Machine Learning di tahap selanjutnya.
